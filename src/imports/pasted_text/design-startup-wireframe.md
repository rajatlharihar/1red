# Low-Fidelity Website Prompt for Figma Make

## Project Overview

Create a clean, minimal, modern low-fidelity website wireframe for a new creative design startup studio inspired by the visual pacing, storytelling, and premium simplicity of:

* urlNK Studio[https://www.nk.studio/studio/](https://www.nk.studio/studio/)

The wireframe should feel:

* Editorial
* Minimal
* Spacious
* Smooth scrolling
* Creative-agency focused
* Experimental but readable
* Premium and modern

The design should prioritize:

* Strong typography hierarchy
* Large spacing
* Scroll-based storytelling
* Clean monochrome wireframe look
* Low-fidelity blocks only (no final UI styling)
* Placeholder imagery/frames
* Focus on structure and interaction flow

# LOW-FIDELITY WIREFRAME RULES

## IMPORTANT

* Use grayscale only.
* No final branding colors.
* Use placeholder blocks for images.
* Focus on layout and spacing.
* Keep typography simple.
* Use wireframe rectangles.
* Show scrolling transitions.
* Show navbar movement behavior.
* Show interaction annotations where needed.
